# Neon Rift

A responsive JavaFX game-GUI assignment project. It demonstrates polished navigation, animation, HUD design, settings controls, keyboard/mouse interactions, graphics and responsive layout containers.

## Run in IntelliJ IDEA

1. Open this folder as a Maven project.
2. Set the Project SDK to JDK 21 (or newer).
3. In the Maven panel, run `Plugins > javafx > javafx:run`.

If you use the green Run button instead, run the `Launcher` class (not `NeonRiftApp`).

Controls on the game screen: use `Arrow Keys` or `WASD` to fly, collect all cyan shards, and avoid pink mines. `P` or `ESC` pauses the mission. The HUD updates your score, shard progress, and shields live. Sound effects and generated ambient music can be enabled from Settings.
